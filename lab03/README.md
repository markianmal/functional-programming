# Лабораторна робота 3: Нездатні до змін структури даних (Варіант 12)

**Предметна область:** Ресторанне меню (`Dish`, `Ingredient`, `allergens`, `meta`).

## 1. Архітектурні рішення
- **Інгредієнти (`Ingredient`):** Реалізовані як `@dataclass(frozen=True, slots=True)`. Забезпечують фіксований оверхед пам'яті, контроль цілісності даних у `__post_init__` та хешованість.
- **Страва (`Dish`):** Основна сутність на `@dataclass(frozen=True, slots=True)`.
  - `ingredients`: збережено в `tuple[Ingredient, ...]` замість `list` (запобігає in-place змінам).
  - `allergens`: збережено у `frozenset[str]` (швидкий пошук $O(1)$, математичні операції множин).
  - `meta`: загорнуто в `MappingProxyType` поверх копії словника, що запобігає модифікації ключів і значень після ініціалізації.
- **Pure Updates:** Будь-які модифікації (додавання інгредієнта, додавання алергену, оновлення цін чи знижок) реалізовані через повернення нового екземпляра за допомогою `dataclasses.replace` та конкатенації незмінних типів.
- **Глибоке заморожування:** Реалізовано функцію `freeze(obj)` для рекурсивного перетворення вкладених словників/списків/множин на `MappingProxyType`, `tuple` та `frozenset`.
