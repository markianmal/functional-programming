# Лабораторна робота №6: Замикання та декоратори як HOF
**Варіант 12: Кешування конвертації даних**

## Реалізований функціонал
- `closures.py`:
  - `make_counter`: замикання зі змінним станом через `nonlocal`.
  - `make_logger`: ін'єкція залежностей через замикання.
  - `make_converter`: конфігурація перетворень даних (коефіцієнт та точність).
- `decorators.py`:
  - `@timed`: вимірювання часу із блоком `finally`, параметризованими одиницями виміру та ін'єкцією `clock`/`logger`.
  - `@retries`: повтори при збоях із бекофом і джиттером, ін'єкцією `sleep`.
  - `@cached`: потокобезпечний кеш із TTL, інвалідацією за предикатом, скиданням і статистикою `hits`/`misses`.
  - `@count_calls`: підрахунок кількості викликів функції з методом `reset()`.
- `main.py`: демонстраційний сценарій конвертації, композиції та інвалідації.
- `tests/`: 22 тести pytest/Hypothesis без реальних очікувань часу.
